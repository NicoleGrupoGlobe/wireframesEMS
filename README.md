# EMS PASA — Wireframes de baja fidelidad por perfil de usuario

Sitio estático con los wireframes low-fi de la plataforma EMS (Energy Management
System) de Globe Power SpA para Parque Arauco S.A. (PASA), organizados por perfil
de usuario (Gerencial, Operacional, Técnico, Auditor y Súper-administrador).

- **Fuente:** Especificación de Pantallas v2.0 (Anexo 07 PASA).
- **Nota:** el mapa gerencial está reconciliado a 3 niveles (País → Centro
  comercial → Tienda/Local) según instrucción v2.1.
- **Confidencial** — documento de diseño para PASA / Globe Power.

## Ver
Abre `index.html`. Cada pantalla muestra el wireframe (SVG) a la izquierda y su
ficha de detalle + justificación UX a la derecha, navegable por perfil.
